仓储业务流程

0. 首次初始化

  1. 定义仓库、区域、货架、层、格的编码规则。
  2. 导入商品表并清理重复 SKU、规格和单位。
  3. 为商品和货位打印条码/二维码标签；供应商已有条码时先映射，不随意覆盖。
  4. 盘点试点范围的期初库存，由负责人确认后建立期初记录。

1. 收货入库

  1. 操作员选择或扫描收货单。
  2. 扫描商品；系统展示名称、规格、预期数量和单位。
  3. 输入实收数量；需要时录入批次、效期、序列号及质检状态。
  4. 少收、超收、破损或待检商品按异常流程登记，不混入可用库存。
  5. 扫描暂存/目标货位；系统展示商品、数量、货位和状态供核对。
  6. 操作员确认；生成入库动作，库存才增加。

未知条码进入“待识别商品”队列，不直接按 AI 猜测结果建档。部分收货、取消和重复扫描需明确状态与防重规则。

2. 上架与移库

  1. 系统可按类别、容量或固定货位规则推荐位置。
  2. 操作员扫描商品或容器，再扫描目标货位标签。
  3. 系统显示商品、数量、来源、目标位置和库存状态供核对。
  4. 确认后生成移库动作并更新货位余额。

首期建议使用“固定货位 + 人工确认”，有了周转和容量数据后再验证动态货位建议。

3. 出库拣货

  1. 根据订单/领料单生成待拣清单。
  2. 按货位提示取货，扫描货位和商品条码。
  3. 输入或扫描确认数量；批次商品按既定 FIFO/FEFO 规则提示。
  4. 系统检查货位、商品、批次、库存状态和可用数量。
  5. 操作员确认后生成出库动作；不足、错货、超拣或取消时按规则处理。

首版是否接订单、支持部分拣货和库存预留要由朋友确认；如果只是内部领用，可先用简单出库单。

4. 盘点与调整

  1. 按货位或商品生成盘点任务，并明确盘点期间是否暂停相关出入库。
  2. 扫描货位、商品并记录实盘数。
  3. 系统展示账面数与实盘差异，不覆盖原始记录。
  4. 复盘或负责人审批后生成盘点调整动作，并记录调整原因。

5. 退货与返库（是否纳入首期待确认）

  1. 关联原出库/销售/领料记录，记录退回商品和数量。
  2. 扫描商品并录入批次或序列号；无法识别时先进入待确认队列。
  3. 退回商品先进入待检/隔离状态，不默认计入可用库存。
  4. 由有权限的人员决定重新上架、维修、报损或退回供应商。
  5. 每次状态变化和货位移动都形成独立动作并关联原单。

每类写操作的共同校验

  • 必须确认操作者、业务类型、商品和数量。
  • 需要货位的操作必须核对货位标签。
  • 记录业务单号或来源，避免重复提交。
  • 操作成功后回显更新结果；失败不得显示为成功。
  • 需要撤销时创建反向动作或调整单，不删除历史记录。
