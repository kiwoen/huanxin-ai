# 成本与商业化

## 成本边界

当前没有仓库规模、商品量、地点、设备和现有系统数据，因此本版不编造人民币报价。正式预算按现场调研后拆项。

| 成本项 | 复用现有底座/低成本试点 | 定制或自研时的成本来源 |
|---|---|---|
| 软件与部署 | 现有电脑/手机、开源版本、自有局域网或低配服务器 | 云服务器、域名、备份、监控、数据库维护 |
| 扫码设备 | 先用手机摄像头或已有扫码枪 | 蓝牙/工业扫码器、耐用标签、热敏打印机 |
| 数据整理 | 导入少量样本，人工核对 | 大量历史商品清洗、条码映射和期初盘点 |
| 实施与培训 | 由业务负责人带员工试点 | 流程梳理、界面定制、现场培训和后续支持 |
| AI/API | 首期可不启用云模型 | API 调用量、图片识别、日志留存和模型评测 |
| 运维 | 小范围手动备份和恢复演练 | 高可用、离线同步、权限审计、升级与客服 |

## 方案路线

| 路线 | 初期投入 | 长期维护 | 适用判断 |
|---|---|---|---|
| 配置开源/现成系统 | 最低，主要是部署、标签和数据整理 | 较低到中等，取决于升级和现场支持 | 朋友的流程基本标准，尽快验证 |
| 现有系统 + 轻量扩展/AI 助手 | 中等，开发缺少的交互或接口 | 中等，需维护扩展兼容性 | 基础收发货可复用，但录入/查询体验有明显缺口 |
| 完全自研 WMS | 最高，需重建库存、权限、审计和测试 | 最高，长期承担缺陷、升级和业务支持 | 只有流程特殊、复用市场已验证且有持续团队时考虑 |

## 预算测算表

现场确认后按如下公式估算，设备部分优先询价复用设备；人员投入按实际人日和服务范围报价。

**首期总成本 = 需求与数据整理 + 软件配置/开发 + 设备与标签 + 部署备份 + 培训试点 + 预留维护**

至少给出三档：只跑通试点、可稳定单仓使用、面向多个仓库/客户产品化。云模型费用独立列项并设置额度上限，不将“免费额度”作为稳定成本基础。

## 可能的商业化方式

- 单仓部署与初始化服务：商品/货位导入、条码规则、培训。
- 按仓库/账号/功能订阅：库存基础版与 AI 辅助版分层。
- 自托管/私有部署与运维支持：面向有数据控制要求的客户。
- 设备与耗材由客户自购或透明代采，不隐藏硬件成本。

以上只是收费路径假设。要产品化，必须验证相邻仓库是否有相同痛点、是否愿意付费、部署维护是否可复制。朋友的单个需求只能证明一个试点机会，不能单独证明市场规模。
